## Step 1: Student Learning Journey

The journey below shows how a learner moves from identifying a study need to receiving AI support and continuing with revision.

| Stage | Student Need / Action | EduMind AI Touchpoint | Expected Outcome |
|---|---|---|---|
| 1. Discover | Learner faces a question or difficult topic. | Open EduMind AI and choose the learning interaction. | Learning need is clearly identified. |
| 2. Ask | Learner types a question or topic. | Question Answer / Explain feature. | Immediate AI-generated response. |
| 3. Understand | Learner needs examples or a simpler explanation. | Explain feature with beginner-friendly guidance. | Better conceptual understanding. |
| 4. Practice | Learner wants to test understanding. | Quiz generation feature. | Practice questions for self-assessment. |
| 5. Revise | Learner needs concise material. | Study Notes / Summarize feature. | Short revision-ready content. |
| 6. Continue | Learner wants to know what to learn next. | Learning Path recommendation. | Structured next learning steps. |

## Step 2: Key User Experience Goal

**Goal:** Reduce the number of separate study tools a learner needs by bringing common AI-powered learning activities into one simple interface.
