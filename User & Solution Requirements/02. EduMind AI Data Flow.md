## Step 1: Data Flow Overview

| Step | Component | Data / Action |
|---:|---|---|
| 1 | Student / User | Enters a question, topic or learning request. |
| 2 | EduMind AI Frontend | Sends the request to the selected feature. |
| 3 | FastAPI Backend | Receives and routes the request to the appropriate module. |
| 4 | Feature Module | Builds an AI prompt for Q&A, explanation, quiz, notes, summary or learning path. |
| 5 | Gemini API | Processes the prompt and generates an AI response. |
| 6 | Backend Response | Returns the generated content to the frontend. |
| 7 | Student / User | Views the final response and continues learning. |

## Step 2: Simplified Flow

**User → Frontend → FastAPI Backend → Feature Module → Gemini API → Backend Response → User**
