## Step 1: Architecture Overview

EduMind AI follows a layered architecture separating the user interface, backend routing, feature modules and external AI service.

## Step 2: Architecture Components

| Layer | Component | Responsibility |
|---|---|---|
| 1. Presentation | HTML / CSS / JavaScript | Collect input and display responses. |
| 2. Application | FastAPI Backend | Receive, validate and route requests. |
| 3. Feature Modules | Q&A, Explanation, Quiz, Notes, Summary, Learning Path | Build feature-specific prompts. |
| 4. AI Integration | Google Gemini API / Gen AI SDK | Generate AI responses. |
| 5. Configuration | Environment variables / .env | Store API credentials securely. |

## Step 3: Request Flow

**User → Frontend → FastAPI Backend → Feature Module → Gemini API → Feature Module → Backend → Frontend → User**
